# Centro Cuídate

App de gestión de Centro Cuídate (citas, ventas, stock, clientes y talleres) y web pública de reservas.

- `index.html` — app de gestión (requiere iniciar sesión).
- `booking.html` — web pública de reserva de talleres.
- `sw.js` — service worker (modo sin conexión y notificaciones).
- `vendor/` — librerías de terceros (jsPDF, licencia MIT).
- `tools/stamp-version.sh` — sella la versión antes de publicar.
- `database.rules.json` — copia de referencia de las reglas de Firebase.

Se publica con GitHub Pages desde la rama `main`.
